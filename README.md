# 植早早

在手机、平板和二合一设备上记录植物生长、养护、光照环境和纪念。这是微信小程序「植早早」的鸿蒙版本，用 ArkTS / ArkUI 编写，面向 HarmonyOS 5.0 及以上的华为应用市场。

当前没有账号，也没有登录。植物、环境、养护记录和照片都只保存在这台设备上。

## 功能

- 主页：植物图片墙、总投入、今日浇水、逾期数量、未来 14 天内的待办，可按名称和状态筛选
- 植物档案：名称、品种、状态、价格、购买途径、种植形式、环境、位置、购买日期、陪伴起始、备注、最多 9 张照片
- 生长环境：自定义名称、光照强度（lux）和每日光照时长，附 lux 参考
- 养护记录：浇水、施肥、修剪、换盆、防治病虫害、测量，可附文字和一张照片
- 提醒：浇水按季节（春、秋 10 天，夏 5 天，冬 15 天），施肥默认 30 天，换盆默认 365 天；每株植物可以单独改间隔。从最近一次同类记录起算，没有记录时从陪伴起始或购买日期起算
- 纪念碑：送人或去世后离开主页和提醒，保留纪念语与陪伴时长，可以恢复
- 备份：导出或合并一份包含照片的 JSON 文件。相同编号会被备份覆盖，其他本机数据保留

状态可选：健康、生长中、休眠、状态一般、需要关注、生病中。种植形式可选：水苔、土培、水培、板植、颗粒。

## 用 DevEco Studio 打开

1. 安装 [DevEco Studio](https://developer.huawei.com/consumer/cn/deveco-studio/) 5.0 或更高版本，并下载 HarmonyOS NEXT SDK（API 12 / 5.0.0 及以上）。
2. 选择「Open」，打开本仓库根目录，等待同步完成。
3. 用手机、平板模拟器或真机运行。工程的 `deviceTypes` 包含 `phone`、`tablet`、`2in1`，窄屏单列、宽屏会把待办和植物墙分成左右两栏。
4. 调试签名可以用 DevEco 的自动签名。正式上架需要在 AppGallery Connect 申请发布证书和 Profile，不要把 `.p12`、`.cer`、`.p7b` 提交到仓库。

包名目前是 `com.zkwwwwww.zaozao`。第一次上架前可以改 `AppScope/app.json5` 里的 `bundleName`；一旦正式发布，包名不能再改。

## 数据

本地关系数据库是 `zaozao.db`，照片在应用沙箱的 `photos` 目录。卸载或清除数据会删掉这些内容，换设备也不会自动出现。需要留底时，到「纪念」页导出备份。

相册和拍照走系统选择器，工程没有申请读取全部照片或网络权限。

日期和提醒算法的可执行检查：

```bash
npm test
```

`logic/format.js`、`logic/reminder.js` 与 `entry/src/main/ets/common/` 里的同名逻辑保持一致。改间隔或日期规则时，两处一起改，并跑上面的检查。

## 上架前还要你本机完成的事

本仓库还不能代替应用市场审核。正式提交前建议：

1. 在 AppGallery Connect 创建应用，包名与工程一致，签好发布证书。
2. 准备应用图标、介绍、截图。图标源文件由 `scripts/make-icons.js` 用几何图形生成，没有第三方素材；需要重新生成时执行 `node scripts/make-icons.js`。
3. 把 `PRIVACY.md` 放到一个公网可访问的网页，填到应用的隐私政策链接。应用里的「隐私说明」是同一份说明的简版。
4. 按《华为应用市场审核指南》自检：应用能完整使用、介绍和截图与实际功能一致、没有隐藏功能。
5. 预留至少一周给审核和修改。

华为「鸿蒙应用开发者激励计划 2026」公开页面写的是：须在 2026 年 3 月 12 日至 9 月 30 日期间首次正式上架到 HarmonyOS 5.0 及之后的华为应用市场，并且单独报名、开通商户。只提交审核、还没通过，不算正式上架。今天如果已经过了该计划的截止日期，请以 [激励计划页面](https://developer.huawei.com/consumer/cn/activity/harmonyos-incentive/2026) 的最新说明为准，不要默认这一轮现金激励仍然开放。

## 目录

```
AppScope/                 应用名、包名、图标
entry/src/main/ets/
  entryability/           窗口与本地数据库初始化
  pages/                  主页、环境、提醒、纪念和各编辑页
  components/             顶栏、空状态、按钮
  common/                 日期、提醒、列表数据
  model/                  数据模型
  store/                  本地数据库、照片、备份
logic/                    可用 Node 跑的日期与提醒检查
scripts/make-icons.js     原创图标
PRIVACY.md                隐私说明
```
